Page Setting Guide

What is Page Setting?

Page Setting allows you to create a profile for the current webpage, storing presets and form configurations specific to this URL.

Getting Started

When you visit a new page, you'll see three options:

  • Create New Profile: Start fresh with a blank configuration for this page
  • Clone from Existing: Copy settings from another page profile you've already created
  • Import Page Profile: Load a previously exported JSON configuration file

URL Matching

When creating a profile, you can choose how the extension matches URLs:

  • Exact Match: Only activates on the exact URL you specify
  • Prefix Match: Activates on any URL starting with the specified prefix

Pro Tip: Use Prefix Match for websites where the URL changes slightly (like pages with IDs or query parameters) but you want the same form-filling behavior.

Quick Actions

Once a profile exists, you can:

  • Edit Page: Open the full editor to modify presets and settings
  • Export Page: Save the entire profile as a JSON file for backup or sharing

Presets Guide

What are Presets?

Presets are saved collections of form field values that can be applied to forms on your page with a single click.

Using Presets

  • Apply Preset: Click the Apply button to fill all form fields with saved values
  • Scan Page: Automatically detect all form fields on the current page
  • Edit Preset: Open the full editor to customize field values and settings

Preset Actions

Each preset has several management options:

  • Edit: Modify preset name, description, and field values
  • Export: Save preset as a JSON file
  • Import: Load a preset from a JSON file
  • Delete: Remove the preset (with confirmation)

Pro Tip: You can create multiple presets for the same page. For example, create one preset for "Test User" and another for "Production User" with different credentials.

Field Types

The extension supports various field types:

  • Text inputs (text, email, password, etc.)
  • Checkboxes and radio buttons
  • Dropdown selects
  • Date pickers and number inputs
  • Range sliders and color pickers

Keyboard Shortcuts

Ctrl + F - Search fields in editor
Tab - Navigate between fields
