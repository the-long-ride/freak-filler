For each test case or flow that interacts with the page, locate the form fields it uses (selectors, test ids, values, types, and any delays or blur behavior) and create a Preset object for that test case if one doesn't already exist.

Produce a single JSON payload matching the Freak Filler extension storage format with the following top-level structure: pages (array), presets (array), presetPageLinks (array), savedValues (array, optional), and settings (optional).

Requirements:
- Use GUIDs for IDs and ISO 8601 timestamps for createdAt/updatedAt.
- Use exactMatch or prefixMatch for page matching; prefer exactMatch if the test uses the full URL.
- Group test cases that are semantically identical into one preset when they use the same field sets and values.
- For each field include these properties: id, type, title, value, testId, querySelector, fillDelay, autoBlur, order, createdAt, updatedAt.
- Prefer stable selectors in this order: data-testid, id, name, then other CSS selectors.
- Output only the JSON object — do not include extra comments or surrounding text.

Field detection rules:
- id: new GUID
- type: one of the FIELD_TYPES (text, search, checkbox, radio, dropdown, datepicker, dynamicDate, range, number, color, clickable)
- title: best user-facing label (from label, aria-label, placeholder, name, data-testid, id)
- value: literal value to set (string/number/boolean) or JSON for dynamicDate
- testId: data-testid attribute if available
- querySelector: robust CSS selector used in the test
- fillDelay: ms (default 0)
- autoBlur: boolean (default false)
- order: integer 1..n (preserve test flow order)
- createdAt and updatedAt: ISO timestamps
